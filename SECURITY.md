# Security reporting and verification

Get official releases, source and SHA-256 lists from https://www.crackedvault.workers.dev/plugins/cracked808s . Signing status and verification steps are at https://www.crackedvault.workers.dev/security . The current public 2.5.3 installer is unsigned. A checksum verifies matching bytes, not safety. Do not disable antivirus, SmartScreen or certificate validation to use this software.

For a detection or suspected vulnerability, contact Bcracked through the verified contact links at https://www.crackedvault.workers.dev/about . Include the version, OS/DAW, exact detection name, SHA-256 and safe reproduction steps. Do not attach private projects, credentials or personal information to public reviews. Keep potentially exploitable details private until a coordinated fix is available. No guaranteed response time is promised.

This is public-beta software provided without warranty. The reported intermittent FL Studio exit crash is not considered fixed by update/signing work. Save work and close the DAW before installing updates. Code signing establishes provenance and integrity, not a guarantee of bug-free or malware-free operation.
